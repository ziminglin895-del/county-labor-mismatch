## 3. 字段清洗规范与核心计量口径

### (1) 招聘人数（Headcount）严格守门
- **实测缺失率**：77.32%（4,754 条中 3,676 条未明确填报具体招工人数）。
- **清洗纪律**：**严格保持空值（NaN），绝不默认补 1**。填报具体的 1,078 条样本平均招聘人数为 5.69 人（中位数 3 人，四分位数 1–5 人），真实反映了县域小微企业招聘普遍不填写招工规模的制度背景。

### (2) 学历要求分类与哑变量编码
- **学历标准分类**：
  - `大专及以上`（177条）：要求大专、本科、硕士、博士等高等学历。
  - `高中/中专`（131条）：要求高中、中专、职高、技校。
  - `初中及以下`（2条）：明确注明初中或小学。
  - `学历不限`（1,644条）：明确注明学历不限。
  - `未注明`（2,802条）：列表卡片未明确标注学历门槛。
- **虚拟变量映射**：
  - `要求大专及以上`：当学历标准分类属于大专/本科/硕士/博士时为 1，否则为 0。
  - `要求本科及以上`：当学历标准分类属于本科/硕士/博士时为 1，否则为 0。
  - `要求硕士及以上`：当学历标准分类属于硕士/博士时为 1，否则为 0。
  - `学历不限`：属于学历不限时为 1，否则为 0。
  - `学历未注明`：未注明时为 1，否则为 0。

### (3) 薪资区间处理
- 剔除“面议”与无效薪资后，4,331 条样本具有清晰的最低与最高月薪数值（有效率 91.1%）。
- 平均最低月薪：4,129.65 元；平均最高月薪：6,415.85 元；平均中位薪资：5,272.75 元，符合中部县域一般劳动力市场的真实工资分布。

### (4) 样本偏薄县标记与稳健性剔除建议
为避免部分县样本量过小导致估计偏误，汇总表设置了 `thin_sample_flag`：
- 若该县总岗位数 `n_ads < 10`，标记为 `1`；否则为 `0`。
- 全省 105 县中共 14 个县为薄样本（含栾川 0、新密 1、嵩县 1、洛宁 1、浚县 1、淇县 1、巩义 2、内黄 2、登封 3、汤阴 5、商城 7、荥阳 8、叶县 9、郏县 9）。
- **实证建议**：基准回归可使用全样本，稳健性检验中剔除 `thin_sample_flag == 1` 的 14 县。
