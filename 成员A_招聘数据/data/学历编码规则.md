# 学历编码规则（成员A）

## 字段

| 列名 | 类型 | 含义 |
|---|---|---|
| edu_canon | 类别 | 学历要求归一化类别 |
| edu_min_level | 1-6 | 有序最低学历档（仅明确门槛）；unlimited/unspecified/other 为空 |
| edu_stated | 0/1 | 是否给出明确学历门槛 |
| edu_unlimited | 0/1 | 学历不限 / 不限 |
| edu_unspecified | 0/1 | 未注明（原字段缺失或空） |
| edu_other | 0/1 | 其他 |
| req_dz | 0/1 | 要求大专及以上 |
| req_bk | 0/1 | 要求本科及以上 |
| req_ss | 0/1 | 要求硕士及以上 |
| req_bs | 0/1 | 要求博士 |
| headcount | 数值/空 | 招聘人数，缺失不填 |
| headcount_missing | 0/1 | 招聘人数是否缺失 |

## 原始取值 → 归一化 → 0/1

| 原始学历要求 | edu_canon | edu_min_level | req_dz | req_bk | req_ss | req_bs |
|---|---|---:|---:|---:|---:|---:|
| 初中及以下 | junior_or_lower | 1 | 0 | 0 | 0 | 0 |
| 高中 | high_school | 2 | 0 | 0 | 0 | 0 |
| 中专/中技 | vocational_secondary | 2 | 0 | 0 | 0 | 0 |
| 中专 | vocational_secondary | 2 | 0 | 0 | 0 | 0 |
| 中技 | vocational_secondary | 2 | 0 | 0 | 0 | 0 |
| 技校 | vocational_secondary | 2 | 0 | 0 | 0 | 0 |
| 大专 | college | 3 | 1 | 0 | 0 | 0 |
| 本科 | bachelor | 4 | 1 | 1 | 0 | 0 |
| 硕士 | master | 5 | 1 | 1 | 1 | 0 |
| 博士 | doctorate | 6 | 1 | 1 | 1 | 1 |
| 学历不限 | unlimited |  | 0 | 0 | 0 | 0 |
| 不限 | unlimited |  | 0 | 0 | 0 | 0 |
| 其他 | other |  | 0 | 0 | 0 | 0 |
| (缺失/空) | unspecified |  | 0 | 0 | 0 | 0 |

## 规则说明

1. 「学历不限」与「不限」同属 edu_unlimited；「未注明」= 原字段缺失；二者互斥，均不计入明确门槛。
2. req_* 为累计口径：req_dz=1 蕴含达到大专档（大专/本科/硕士/博士）。
3. 高中/中专/中技/技校 同档（level=2），中专/中技与技校、中专原值全部归 vocational_secondary。
4. 「其他」不进入任何 req_*，也不进入 of_stated 分母。
